# Arrivées en attente

Cette vue présente les réservations dont l’arrivée se situe dans la période recherchée, aujourd’hui par défaut, mais qui ne sont pas encore enregistrées comme arrivées. Elle retient les statuts **Confirmée** et **Validée**, exclut les annulations et les dossiers sans participant.

La recherche avancée permet de choisir la période, le centre, le type de réservation et une catégorie d’unité locative. Les lignes indiquent notamment le client, les dates, le centre, le nombre de participants, les alertes et la situation de paiement.

Ouvrez une réservation pour effectuer les contrôles nécessaires avant l’arrivée et lancer l’action de check-in lorsque le dossier est prêt.
