# Séjours présents aujourd’hui

Cette vue affiche les réservations dont la période comprend la date du jour et dont le statut est **Arrivée / Checked-in** ou **Départ / Checked-out**. Elle donne une vue opérationnelle des séjours présents ou quittant le centre aujourd’hui.

Chaque ligne reprend les dates, le statut, le client, le centre, le nombre de participants, les alertes et la situation financière. Les réservations les plus récemment créées apparaissent en premier.

L’action **Planning** permet de produire le planning correspondant. Ouvrez une réservation pour vérifier ses consommations, ses participants et les opérations encore nécessaires.
