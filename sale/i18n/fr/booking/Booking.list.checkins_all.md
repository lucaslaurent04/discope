# Arrivées prévues

Cette vue présente les réservations dont l’arrivée se situe dans la période recherchée, aujourd’hui par défaut. Elle inclut les réservations confirmées, validées ou déjà enregistrées comme arrivées, exclut les annulations et ne retient que les dossiers comportant au moins un participant.

La recherche avancée permet de choisir la période, le centre, le type de réservation et une catégorie d’unité locative. Chaque ligne affiche les dates, le statut, le client, le centre, le nombre de participants et la situation financière.

Cette liste sert à préparer et suivre les arrivées. L’export d’impression produit le listing des arrivées pour les dates et le centre sélectionnés.
