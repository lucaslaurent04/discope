# Départs en attente

Cette vue présente les réservations dont le départ se situe dans la période recherchée, aujourd’hui par défaut, et qui sont encore confirmées, validées ou en cours de séjour. Elles n’ont donc pas encore terminé l’étape de départ.

La recherche avancée permet de choisir la période, le centre et une catégorie d’unité locative. Chaque ligne affiche les dates, le statut, le client, le centre, le nombre de participants, les alertes et la situation financière.

Ouvrez une réservation pour contrôler les consommations et services supplémentaires, puis effectuer le check-out lorsque le dossier est prêt.
