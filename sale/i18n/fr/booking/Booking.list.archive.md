# Réservations archivées

Cette vue présente les réservations placées dans les archives et rattachées aux équipes de gestion accessibles à l’utilisateur. Les plus récemment créées apparaissent en premier.

Chaque ligne reprend la réservation, le client, les dates du séjour, le statut, le centre, le nombre de participants, le prix et la situation de paiement. Les indicateurs d’annulation et d’alerte restent visibles afin de conserver le contexte du dossier.

Ouvrez une ligne pour consulter son historique. L’action **Désarchiver** replace les réservations sélectionnées dans les listes actives lorsque leur suivi doit reprendre.
