# Départs issus du channel manager à facturer

Cette vue affiche les réservations issues du channel manager dont le statut est **Départ / Checked-out**. Elle permet d’identifier les dossiers externes qui doivent poursuivre leur traitement après le séjour, notamment vers la facturation.

Chaque ligne présente le client, les dates, le centre, le type, le nombre de participants, le prix, le montant payé et le statut de paiement. Les indicateurs d’annulation et d’alerte aident à repérer les cas particuliers.

Les actions groupées permettent, selon vos droits, d’archiver les dossiers, de mettre leur statut à jour ou de lancer la facturation rapide. Vérifiez les services et montants avant toute émission de facture.
