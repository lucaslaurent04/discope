# Départs prévus

Cette vue présente les réservations dont le départ se situe dans la période recherchée, aujourd’hui par défaut. Les simples devis sont exclus afin de concentrer la liste sur les séjours effectivement engagés.

La recherche avancée permet de choisir la période, le centre et une catégorie d’unité locative. Chaque ligne reprend les dates, le statut, le client, le centre, le nombre de participants, les alertes et la situation financière.

Cette liste donne une vue d’ensemble des départs à organiser ou déjà traités pour la période. Ouvrez une réservation pour vérifier ses consommations, ses suppléments et les étapes restantes avant la facturation ou la clôture.
