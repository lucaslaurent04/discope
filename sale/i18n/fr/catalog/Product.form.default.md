# Fiche d’édition d’un produit

Un produit est une variante concrète d’un modèle de produit. Il représente un consommable ou un service qui peut être ajouté à une réservation, vendu au point de vente ou intégré dans un pack. Chaque variante possède son propre **SKU**, même lorsqu’elle partage son libellé et sa description avec d’autres variantes du même modèle.

### Informations générales

Le **modèle de produit** porte les caractéristiques communes du service, tandis que cette fiche définit la variante commercialisée. Le libellé, le SKU, la description et les classifications permettent de retrouver le produit dans le catalogue et dans les documents. Les classes d’âge et de tarif servent notamment à distinguer plusieurs variantes d’un même service.

### Vente et prix

L’option **Peut être vendu** détermine si le produit peut être ajouté à une vente. Les prix sont définis par liste de prix et complétés par les règles fiscales et comptables applicables. Un produit peut disposer de son **propre prix**, autoriser une adaptation tarifaire ou être proposé gratuitement selon sa configuration. Désactiver la vente empêche son utilisation dans de nouvelles opérations sans supprimer son historique.

### Effet opérationnel

La configuration indique si le produit correspond à une activité, un repas, un transport, une fourniture, un hébergement ou une autre prestation. Lorsqu’un service est planifiable, sa réservation génère des consommations utilisées dans les plannings. La quantité peut dépendre des unités, des participants, des unités locatives ou de la durée du séjour selon le mode de comptabilisation défini par le modèle.

### Attributs, familles et groupes

Les attributs décrivent les variantes disponibles pour un même modèle. Les familles et groupes de produits déterminent la place du produit dans le catalogue, les écrans de sélection et les offres accessibles selon le centre. Le code de regroupement peut également être utilisé pour présenter ensemble des lignes liées dans les documents.

### Produits du pack

Si le produit est un pack, l’onglet **Produits du pack** définit les produits et quantités qui le composent. Le pack peut utiliser son propre prix ou calculer son montant à partir de ses composants. Lorsqu’une composition déjà utilisée doit changer, il est préférable de désactiver l’ancienne version et de créer une nouvelle variante afin de préserver les réservations existantes.
